= What's new in ONTAP 9.20.1 for ASA r2 systems
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Learn about the new capabilities available in ONTAP 9.20.1 for ASA r2 systems.

== SAN data migration

[cols="2,4" options="header"]
|===
| Update
| Description

| link:../manage-data/migrate-svm-from-asa-r2.html[Support for non-disruptive storage VM migration from ASA r2 systems to ASA and AFF systems]
| You can non-disruptively migrate a storage virtual machine (VM) from a 2-node ASA r2 cluster to a 2-node ASA or a 2-node AFF cluster. Existing host mappings and storage unit configurations for LUNs and namespaces are maintained during migration, reducing operational effort and risk. 

| link:../manage-data/migrate-svm.html[Support for improved performance after migrating storage VMs from an ASA system to an ASA r2 system]
| ONTAP reduces additional read latency and CPU usage that can occur after storage virtual machines (VMs) are migrated from an ASA system to an ASA r2 system.
|===

== Security
[cols="2,4" options="header"]
|===
| Update
| Description
| link:../learn-more/additional-supported-ontap-features.html#fc-sp-3-authentication-and-encryption[Support for FC-SP-3 authentication and encryption with Broadcom secure HBAs]
| ONTAP supports Fibre Channel Security Protocol 3 (FC-SP-3) authentication and encryption on Broadcom secure HBAs with ASA r2 systems. FC-SP-3 support enables hardware-level end-to-end encryption and device authentication to protect data in flight between FC and NVMe/FC SAN hosts and ONTAP storage systems while aligning with T11 Fibre Channel security standards.
|===

== Storage resource management
[cols="2,4" options="header"]
|===
| Update
| Description
| link:../learn-more/additional-supported-ontap-features.html#storage-efficiency[Support for simplified reporting of storage efficiency data reduction rate]
| The storage efficiency data reduction rate (DRR) provides a more precise assessment of ONTAP storage efficiency space savings by including only reducible data. In ONTAP 9.19.1 and earlier, the DRR includes both reducible and non-reducible data.
|===

== System manager
[cols="2,4" options="header"]
|===
| Update
| Description

| link:../learn-more/additional-supported-ontap-features.html#storage-efficiency[Support for certificate and user password expiration alerts]
| System Manager displays a dashboard health alert 30 days before a cluster or storage virtual machine (SVM) certificate expires and updates it daily with the days remaining before expiration. 

Also, the role associated with a user account is configured for password expiry alerts, the user receives a top-of-page banner alert in System Manager immediately after logging in, beginning 14 days before the password expires. The alert is updated each time the user logs in to show the number of days remaining until the password expires. 

| link:../learn-more/additional-supported-ontap-features.html#autosupport[Support for additional AutoSupport alerts]
| System Manager displays new AutoSupport alerts that can help you address AutoSupport configuration issues.
|===
